# `bevy_abi_mod_host_sys`

Low-level host FFI execution engine, registry, and dynamic library loader for [`bevy_abi_mod`](../bevy_abi_mod) (`ABI 0.3.0`, `v0.3.0`).

Isolates all host-side `unsafe` code behind sealed `pub(crate)` `ffi/` submodules and documented safety invariants (`#![deny(improper_ctypes_definitions, clippy::undocumented_unsafe_blocks, clippy::missing_safety_doc)]`) so [`bevy_abi_mod_host`](../bevy_abi_mod_host) and all companion/facade crates enforce `#![forbid(unsafe_code)]`:

- **`HOST_API` (`BamHostApi`)**: All **68/68** live `extern "C"` function-pointer slots implemented end-to-end (including all 18 ABI `0.3.0` slots in [`v03_ext`](./src/ffi/v03_ext.rs)).
- **`ModRegistry`**: Generation-tracked copy-on-write (`Arc<RegistrySnapshot>`) handle, UUID, `"bam.v0.*"` symbol, relation, declarative `BamFieldDesc`, and VTable registry.
- **`GuestSystem`, `ModScheduleSetRegistry` & `ModScheduleSetRewirePass`**: Implements Bevy's `System` trait over `BamSystemDesc`, populates `FilteredAccessSet<ComponentId>`, supports Bevy `0.20` `.chain()` / `.chain_weak()` / `.before_weak()` / `.after_weak()` decoupled schedule sets, schedule-only hot-rewiring, `NON_SEND` main-thread pinning, and `FallbackErrorHandler` fault bridging.
- **`HostIter`, `CascadeHierarchyCache` & Zero-Arena Parallelism**: Zero-copy `Table` column slices, batched `SparseSet` indirect row pointers, non-destructive `iter_count`, lazy per-`(World, RelationComponentId)` `CascadeHierarchyCache` (`iter_up_cascade` with Brent cycle guard), resource change-detection ticks (`BamChangeTicks`), `par_for_each_chunk`, and zero-arena `par_for_each_chunk_readonly`.
- **`HostCommands`, `CommandArena` & `ModRelationGraph`**: Per-system bump-allocated deferred command queue with bounded arena/spawn quota hooks, LIFO `cmd_checkpoint` / `cmd_rollback` transactions, typed entity relationships (`EXCLUSIVE`, `SYMMETRIC`, `ACYCLIC` / `CYCLE_DETECTED`, `CASCADE_DELETE`, `CLEANUP_REMOVE`), and `EntityWorldMut` application (`ComponentHooks`, `#[require(...)]`, `ChildOf` / `Children`).
- **`DROP_PAGES`, `WorldDropGuard`, & `DynamicComponentHookMap`**: Wait-free `ArcSwapOption` paged drop trampolines (up to `4,096` slots) with two-condition reclamation plus 5-hook lifecycle, `clone_fn`, and `required_init_descs` dispatch preventing use-after-`dlclose`.
- **`validation`** (`ffi/validation.rs`): Safe host-side witness field introspection/migration, declarative `BamFieldDesc` `ReflectFromPtr` / `ReflectComponent` / `ReflectResource` slot pools, and cross-`World` (`SubApp`) component/resource extraction.
- **`ModHost`, Zero-Copy Reload, `migrate_component_column`, `BamSymbolTable` & `ModNamedObjects`**: Shadow-copy library loading (`LoadOptions`), optional `signature-verification` delegated to [`bevy_abi_mod_trust`](../bevy_abi_mod_trust) (`.sig`, `.bam_sig`, `.bampack`, CA/SSHKRL), transactional init rollback, deterministic 5-step unload, zero-copy `schema_fingerprint` column retention, zero-per-entity-allocation `migrate_component_column`, monotonic reload-stable UTF-8 symbol interning, and persistent named objects.

Application authors should depend on `bevy_mod_abi` or `bevy_abi_mod` rather than using this `-sys` crate directly.
