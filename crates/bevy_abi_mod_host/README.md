# `bevy_abi_mod_host`

Safe (`#![forbid(unsafe_code)]`), **slim headless** Bevy ECS (`v0.20+`) integration crate for [`bevy_abi_mod`](../bevy_abi_mod) (`ABI 0.3.0`, `v0.3.0`).

`bevy_abi_mod_host` intentionally pulls in **zero** `bevy_render`, `bevy_reflect`, `bevy_scene`, `bevy_asset`, or `notify` dependencies, making it ideal for headless dedicated servers, simulations, and CLI tools while providing the idiomatic Bevy plugin, budgets, extension traits, schedule/set bindings, `mod.toml` SemVer DAG loading, and lifecycle messages:

- **`AbiModPlugin`**: Initializes `ModRegistry`, `ModHost`, `ModQuarantine`, `ModScheduleMap`, `ModVisibleSets`, `ModUnloadHooks`, `ModBudgetPolicy` / `ModBudgetTelemetry`, `WorldDropGuard`, and `Messages<ModLoaded>` / `Messages<ModUnloaded>` / `Messages<ModSystemFaulted>` / `Messages<ModBudgetBreach>`.
- **`ModBudgetPolicy` & `ModBudgetTelemetry`**: Enforces global and per-mod `CommandArena` byte caps (`CAPACITY_EXCEEDED`), atomic per-frame spawn quotas across all spawn commands, and sliding-window `p50_us`/`p99_us` frame-time watchdogs with auto-quarantine and `ModBudgetExt` (`App`/`World`) configuration.
- **`ModAppExt`, `ModWorldExt` & `ModUnloadHooks`**: Exposes Bevy components (`ComponentOptions`), singleton resources (`register_mod_resource`), buffered POD and non-POD messages (`register_mod_message`, `register_mod_non_pod_message`), triggerable `Event` / `EntityEvent` types, custom schedules (`ScheduleId::custom`), `"host::<name>"` visible `SystemSet`s, `load_mods_dir` / `ModDependencyGraph` DAG resolution via [`bevy_abi_mod_manifest`](../bevy_abi_mod_manifest), and extensible `ModUnloadHooks` for decoupled companion cleanup.
- **`ModCommandsExt`**: Queues deferred mod loads, reloads, and unloads safely via Bevy `Commands`.
- **`ModQuarantine`**: Supports runtime inspection and `reenable(mod_id, system_name)` recovery for quarantined guest systems.
- **Optional Feature Integrations**: `strict-ffi-checks`, `diagnostics` (aggregate & per-mod `bevy_diagnostic` counters including budget breaches, p99 time, spawns, and arena peak bytes), and `signature-verification` (`ModTrustPolicy` + `evict_revoked_mods` backed by [`bevy_abi_mod_trust`](../bevy_abi_mod_trust)). Optional Bevy subsystem bridges, render/material extraction, dynamic reflection/savegames/telemetry, and hot-reload watching live in dedicated companion crates [`bevy_abi_mod_bridges`](../bevy_abi_mod_bridges), [`bevy_abi_mod_render`](../bevy_abi_mod_render), [`bevy_abi_mod_reflect`](../bevy_abi_mod_reflect), and [`bevy_abi_mod_watcher`](../bevy_abi_mod_watcher) (all re-exported by [`bevy_abi_mod`](../bevy_abi_mod) and [`bevy_mod_abi`](../bevy_mod_abi)).

All `unsafe` FFI internals, Bevy `System` bridging, `HostIter` chunk iteration, `CommandArena` buffers, and `libloading` calls live in [`bevy_abi_mod_host_sys`](../bevy_abi_mod_host_sys).
