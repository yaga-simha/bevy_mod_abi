# `bevy_abi_mod_sys`

Strictly `#![no_std]`, **zero-dependency** C-ABI `0.3.0` (`0x0003_0000`) wire contract for [`bevy_mod_abi`](../bevy_mod_abi).

This crate defines every cross-boundary type, descriptor, vtable header, error code, slot offset, and trait shared by the Bevy host, procedural macros, Rust guest SDK, `bevy_bql` compilers, and non-Rust guests via the [`include/bevy_abi_mod.h`](../../include/bevy_abi_mod.h) header generated by [`bevy_abi_mod_sdk_gen`](../bevy_abi_mod_sdk_gen):

- **Wire Primitives & Handles**: `FfiResult` (including `CYCLE_DETECTED = 16`), `FfiBool`, `FfiOption<T>`, `StrView`, `FfiSlice<T>`, `FfiEntity`, `FfiChildOf`, `FfiAssetHandle`, `FfiAssetLoadState`, `BamComponent`, `BamSystem`, `BamSystemSet`, `BamSymbol`, `ComponentUuid` (keyed `const` SipHash-2-4-128 via `ComponentUuid::from_parts`), `ScheduleId`, `AccessMode`, `BamEventKind`, `BamChangeTicks`, `BamColumnInfo`, and `BAM_LOG_*` levels.
- **Extensible Descriptors & `offsets`**: `BamManifest`, all 68 live slots of `BamHostApi` (`552` B on 64-bit / `280` B on 32-bit, frozen `MIN_V0_2_SIZE` and `MIN_V0_3_SIZE`), `bevy_abi_mod_sys::offsets` (`<FIELD>`, `OFF64_*`, `OFF32_*`, `SLOT_COUNT = 68`, `SIZE_64 = 552`, `SIZE_32 = 280`), `BamSystemDesc`, `BamQueryDesc`, `BamTermDesc`, `ComponentDesc` (including `schema_fingerprint`, `BamFieldDesc`, `BamFieldKind`, and `BamRequiredComponent`), `BamObserverDesc`, `BamTriggerDesc`, `BamRelationDesc` (`BAM_RELATION_FLAG_{EXCLUSIVE, CASCADE_DESPAWN, CASCADE_DELETE, SYMMETRIC, ACYCLIC, CLEANUP_REMOVE}`), `BamLayoutInfo`, `BamRowMigrateFn`, `BamScheduleSetDesc` (`BAM_SCHEDULE_SET_FLAG_{SEQUENCE, SEQUENCE_WEAK, PARALLEL, BEFORE_WEAK, AFTER_WEAK}`), `VTableHeader`, and `ExtensibleStruct` prefix reading.
- **POD & Component Traits**: `ModComponent`, `RawInsertable`, and `AbiPod` (implemented strictly for fixed-width, bit-valid, zero-drop C-compatible types without implicit padding).

`bevy_abi_mod_sys` has zero external dependencies (not even `alloc` or `std`) so host, proc-macro, SDK-generator, compiler, and guest crates share one identical binary contract without pulling in Bevy internals.
