# `bevy_abi_mod_sys`

Strictly `#![no_std]`, **zero-dependency** C-ABI `0.3.0` (`0x0003_0000`) wire contract for [`bevy_abi_mod`](../bevy_abi_mod).

This crate defines every cross-boundary type, descriptor, vtable header, error code, and trait shared by the Bevy host, procedural macros, Rust guest SDK, and non-Rust guests via the [`include/bevy_abi_mod.h`](../../include/bevy_abi_mod.h) header generated by [`bevy_abi_mod_sdk_gen`](../bevy_abi_mod_sdk_gen):

- **Wire Primitives & Handles**: `FfiResult`, `FfiBool`, `FfiOption<T>`, `StrView`, `FfiSlice<T>`, `FfiEntity`, `FfiChildOf`, `FfiAssetHandle`, `FfiAssetLoadState`, `BamComponent`, `BamSystem`, `BamSystemSet`, `BamSymbol`, `ComponentUuid` (`const` SipHash-2-4-128), `ScheduleId`, `AccessMode`, `BamEventKind`, `BamChangeTicks`, `BamColumnInfo`, and `BAM_LOG_*` levels.
- **Extensible Descriptors**: `BamManifest`, 68-slot `BamHostApi` (`#[repr(C)]` function-pointer table with frozen `MIN_V0_2_SIZE` and `MIN_V0_3_SIZE`), `BamSystemDesc`, `BamQueryDesc`, `BamTermDesc`, `ComponentDesc` (including `schema_fingerprint`, `BamFieldDesc`, `BamFieldKind`, and `BamRequiredComponent`), `BamObserverDesc`, `BamTriggerDesc`, `BamRelationDesc`, `BamLayoutInfo`, `BamRowMigrateFn`, `BamScheduleSetDesc`, `VTableHeader`, and `ExtensibleStruct` prefix reading.
- **POD & Component Traits**: `ModComponent`, `RawInsertable`, and `AbiPod` (implemented strictly for fixed-width, bit-valid, zero-drop C-compatible types without implicit padding).

`bevy_abi_mod_sys` has zero external dependencies (not even `alloc` or `std`) so host, proc-macro, SDK-generator, and guest crates share one identical binary contract without pulling in Bevy internals.
