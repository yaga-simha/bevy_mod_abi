# ADR 0002: ABI v0.2 Wire Specification, Unified Descriptors, Complete `BamHostApi`, and Type Vocabulary

- **Status:** Accepted
- **Date:** 2026-11-11
- **Tracking Items:** `C-01`..`C-13`, `L-08`, `M-04`, `M-05`, `N-02` (cross-references: `B-06`, `B-07`, `B-08`, `P-02`, `P-04`, `P-05`, `L-02`)
- **Target Crates:** `bevy_abi_mod_sys`, `bevy_abi_mod_macros`, `bevy_abi_mod_host_sys`, `bevy_abi_mod_guest_sys`, `include/bevy_abi_mod.h` (`xtask header`)

---

## 1. Context & Problem Statement

ABI `0.1.x` accumulated structural technical debt across four independent growth phases:

1. **Combinatorial descriptor explosion (`C-01`):** Six system descriptor structs (`SystemDescriptor`, `MultiQuerySystemDescriptor`, plus four `V2`/`V3` aliases), seven registration function typedefs, and two duplicated 100+ line host parsers existed for what is fundamentally one concept (a system with `N >= 0` queries, each having `M >= 0` component/filter/resource terms).
2. **Broken forward/backward size checks (`C-02`, `C-08`, `C-09`):** `MIN_V1_SIZE = size_of::<Self>()` rejected older callers whenever a field was appended; `GuestApp::from_raw` required `size_of::<HostApi>()` up front; `validate_raw_slot` cast bare `fn` pointers to `usize` (`sizeof(fn) == sizeof(usize)` assumption) instead of using `Option<extern "C" fn(...)>`; and `flags` were never checked, preventing future flag bits.
3. **Split API discovery & global/TLS ambient state (`C-03`, `C-04`):** `HostApi` carried only 8 slots while commands and resources were looked up by un-namespaced strings with 2–4 fallback aliases (`"cmd_spawn_empty"` / `"host_cmd_spawn_empty"`, etc.) via context-free `GetProcAddressFn(*const c_char)`, forcing the host to rely on `thread_local! CURRENT_REGISTRY`, `ACTIVE_INIT_CONTEXT`, and process-global `GLOBAL_SYMBOLS`.
4. **String lookups on hot paths & weak component identity (`C-05`, `C-10`, `C-13`):** Every `cmd_insert_component` and `res_readonly` validated UTF-8 and ran SipHash; `ComponentUuid::from_name` hashed bare struct names with two correlated FNV-1a lanes (guaranteeing cross-mod collisions on `"Health"` or `"Position"` and ignoring layout mismatches); and chunk iterators exposed no UUID/layout metadata to catch guest type confusion.
5. **Version semantics, taxonomy, C namespace & macro VTables (`C-06`, `C-07`, `C-11`, `C-12`, `L-08`, `M-04`, `M-05`, `N-02`):** `0.x` minor bumps were treated as backward-compatible; `FfiResult` lacked granular error codes and duplicated every constant in PascalCase; `FfiBool` was a bare `u8` type alias; `u128`/`i128`/`usize`/`isize` were marked cross-language `AbiPod`; `bevy_abi_mod.h` was hand-maintained with unprefixed C identifiers; mod manifests were optional; generated VTables lacked headers and silently no-op'd invalid setters; and type names varied across layers.

Because `0.x` allows a clean breaking minor bump before `1.0`, we consolidate every wire-level change into **ABI `0.2.0`**.

## 2. Decision: ABI `0.2.0` Wire Specification

### 2.1 ABI Version Packing & `0.x` Compatibility Rules (`C-06`)

ABI versions are packed into a `u32` as `(major << 24) | (minor << 16) | patch`.

#### Rust (`bevy_abi_mod_sys`)

```rust
pub const ABI_VERSION_MAJOR: u32 = 0;
pub const ABI_VERSION_MINOR: u32 = 2;
pub const ABI_VERSION_PATCH: u32 = 0;

pub const fn pack_abi_version(major: u32, minor: u32, patch: u32) -> u32 {
    assert!(major <= 0xFF, "ABI major version exceeds 8-bit range (0..=255)");
    assert!(minor <= 0xFF, "ABI minor version exceeds 8-bit range (0..=255)");
    assert!(patch <= 0xFFFF, "ABI patch version exceeds 16-bit range (0..=65535)");
    (major << 24) | (minor << 16) | patch
}

pub const fn unpack_abi_version(version: u32) -> (u32, u32, u32) {
    ((version >> 24) & 0xFF, (version >> 16) & 0xFF, version & 0xFFFF)
}

pub const ABI_VERSION: u32 =
    pack_abi_version(ABI_VERSION_MAJOR, ABI_VERSION_MINOR, ABI_VERSION_PATCH); // 0x0002_0000

/// Cargo-aligned SemVer compatibility rule:
/// - Pre-1.0 (`major == 0`): minor bumps are breaking; `host_major == 0 && guest_major == 0 && host_minor == guest_minor`
///   is required (patch is ignored on wire-identical minor versions).
/// - Post-1.0 (`major >= 1`): `host_major == guest_major && guest_minor <= host_minor` (patch is ignored).
pub const fn abi_version_is_compatible(host_version: u32, guest_version: u32) -> bool {
    let (h_maj, h_min, _) = unpack_abi_version(host_version);
    let (g_maj, g_min, _) = unpack_abi_version(guest_version);
    if h_maj == 0 || g_maj == 0 {
        h_maj == 0 && g_maj == 0 && h_min == g_min
    } else {
        h_maj == g_maj && g_min <= h_min
    }
}
```

#### C99 (`include/bevy_abi_mod.h`)

```c
#define BAM_ABI_VERSION_MAJOR 0u
#define BAM_ABI_VERSION_MINOR 2u
#define BAM_ABI_VERSION_PATCH 0u
#define BAM_PACK_ABI_VERSION(maj, min, pat) \
    ((((uint32_t)(maj) & 0xFFu) << 24) | (((uint32_t)(min) & 0xFFu) << 16) | ((uint32_t)(pat) & 0xFFFFu))
#define BAM_ABI_VERSION BAM_PACK_ABI_VERSION(BAM_ABI_VERSION_MAJOR, BAM_ABI_VERSION_MINOR, BAM_ABI_VERSION_PATCH)
```

### 2.2 C Namespace Policy & Single-Source Header Generation (`C-12`)

1. **Strict C Prefixing:** Every identifier emitted into `include/bevy_abi_mod.h` uses:
   - `Bam*` for `typedef struct`, opaque handle typedefs, and function pointer typedefs (`BamHostApi`, `BamSystemDesc`, `BamResult`, `BamBool`, `BamComponent`, `BamEntity`, `BamIter`, `BamCommands`, `BamLoadCtx`, `BamSystemCtx`, `BamHostCtx`, `BamInstance`).
   - `BAM_*` for `#define` constants, flags, limits, and result/mode/schedule discriminants (`BAM_RESULT_OK`, `BAM_ACCESS_READ`, `BAM_SCHEDULE_UPDATE`, `BAM_COMPONENT_INVALID`, `BAM_MAX_TERMS_PER_QUERY`).
   - `bam_*` for `static inline` C99 convenience helpers (`bam_str_view`, `bam_version_is_compatible`).
   - Exported guest entry-point symbol names remain `bevy_abi_mod_manifest`, `bevy_abi_mod_init`, and `bevy_abi_mod_shutdown` (`extern "C"` linkage).
2. **Single-Source Generation (`cargo xtask header`):**
   - `crates/bevy_abi_mod_sys` is the **sole source of truth**.
   - `cargo xtask header` generates `include/bevy_abi_mod.h` via `cbindgen` (configured with `[export.rename]` / prefix rules) and appends machine-generated C11/C99 compile-time layout assertions (`_Static_assert` / `typedef char bam_assert_...[(cond) ? 1 : -1]`) for `sizeof(...)` and `offsetof(...)` computed directly from Rust `core::mem::size_of` and `core::mem::offset_of!`.
   - Remove `bevy_abi_mod.h` from `.gitignore`; CI runs `cargo xtask header && git diff --exit-code include/bevy_abi_mod.h`.

#### `FfiBool` (`BamBool`) (`N-02`)

```rust
#[repr(transparent)]
#[derive(Debug, Copy, Clone, PartialEq, Eq, Hash, Default)]
pub struct FfiBool(pub u8); // C: typedef uint8_t BamBool;

impl FfiBool {
    pub const FALSE: Self = Self(0); // C: BAM_FALSE
    pub const TRUE: Self = Self(1);  // C: BAM_TRUE

    #[inline]
    pub const fn get(self) -> bool {
        self.0 != 0
    }
}

impl From<bool> for FfiBool {
    #[inline]
    fn from(value: bool) -> Self {
        Self(value as u8)
    }
}

impl From<FfiBool> for bool {
    #[inline]
    fn from(value: FfiBool) -> Self {
        value.get()
    }
}
```

#### `ComponentUuid` (`BamComponentUuid`) — Namespaced Identity & Layout Fingerprint (`C-10`)

`ComponentUuid` retains its `[u8; 16]` byte-array representation (`size = 16`, `align = 1` across **every** 32-bit and 64-bit C ABI, avoiding x86 SysV vs MSVC `uint64_t` alignment divergence):

```rust
#[repr(C)]
#[derive(Debug, Copy, Clone, PartialEq, Eq, Hash, Default)]
pub struct ComponentUuid {
    pub bytes: [u8; 16], // C: typedef struct BamComponentUuid { uint8_t bytes[16]; } BamComponentUuid;
}
```

1. **Canonical Namespaced Name (`"<namespace>::<Name>"`):**
   - **Host (`#[derive(ModComponent)]`):** Defaults to `concat!(module_path!(), "::", stringify!(StructName))`, overridable via `#[mod_component(name = "my_game::Health")]` or `#[mod_component(namespace = "my_game")]`.
   - **Guest (`GuestApp::register_component::<T>()`):** Prefixes unqualified names with the mod's manifest name (`"<manifest.name>::<Name>"`), unless the name already contains `"::"`.
2. **Const SipHash-2-4-128 with Layout Fingerprint:**
   - `ComponentUuid::from_parts(canonical_name: &str, size: usize, align: usize, field_schema_hash: u64) -> Self` runs `const` SipHash-2-4-128 (fixed domain-separation key `k0 = 0x4241_4d5f_5555_4944`, `k1 = 0x5630_5f32_5349_5048` — `"BAM_UUIDV0_2SIPH"`) over:
     - `canonical_name.as_bytes()` + `0xFF` separator,
     - `(size as u64).to_le_bytes()`,
     - `(align as u64).to_le_bytes()`,
     - `field_schema_hash.to_le_bytes()` (`0` for opaque non-`AbiPod` VTable-only components whose host layout is intentionally hidden across Rust versions; const hash of `(field_name, field_type_tag, field_offset)` tuples for `#[repr(C)]` `AbiPod` structs).
   - `ComponentUuid::from_canonical_name(canonical_name: &str)` uses `field_schema_hash = 0` for opaque handle/VTable types, and `ComponentUuid::parse_hex("xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx")` supports explicit `#[mod_component(uuid = "...")]` overrides at compile time.
3. **Host Collision Check (`S-08` + `C-10`):**
   - Re-registering an existing canonical name succeeds **only** if `(uuid, size, align)` match identically (hot-reload idempotence); any divergence fails with `FfiResult::TYPE_MISMATCH` (`15`).

### 2.4 `ExtensibleStruct`, `Option<fn>`, and Flag/Reserved Rules (`C-02`, `C-08`, `C-09`)

1. **Every foreign function pointer is `Option<unsafe extern "C" fn(...)>` (`C-08`):**
   Because Rust guarantees null-pointer niche optimization on `Option<extern "C" fn(...)>`, an all-bits-zero slot is a valid `None` on every platform. `ExtensibleStruct::validate_raw_slot` and `HostApi` `usize` byte-probing are **completely deleted**.
2. **Frozen `MIN_V0_2_SIZE` (`C-02`):**
   Every extensible struct defines `MIN_V0_2_SIZE` via `core::mem::offset_of!(Self, <last_v0_2_field>) + core::mem::size_of::<LastFieldTy>()` (never `size_of::<Self>()`), accompanied by `#[cfg(target_pointer_width = "64")]` and `#[cfg(target_pointer_width = "32")]` compile-time `const` assertions.
   - **Host reading guest descriptor:** Copies `min(raw_size, size_of::<Self>())` bytes into a zeroed `Self` buffer (`read_extensible_struct`) after verifying `raw_size >= Self::MIN_V0_2_SIZE`.
   - **Guest reading `BamHostApi`:** Verifies `api.struct_size >= BamHostApi::MIN_V0_2_SIZE` for mandatory core `v0.2` slots, and for any future `v0.3+` appended slot checks `api.struct_size as usize >= offset_of!(BamHostApi, future_slot) + size_of::<Option<FutureFn>>()` at the call site rather than requiring `api.struct_size >= size_of::<BamHostApi>()` at init!
3. **Strict Flag & Reserved Validation (`C-09`):**
   - Unknown bits in any `flags` field (`flags & !KNOWN_FLAGS_MASK != 0`) MUST be rejected with `FfiResult::UNSUPPORTED` (`14`).
   - Non-zero values in any `reserved*` field (`reserved0 != 0`) MUST be rejected with `FfiResult::INVALID_ARGUMENT` (`8`).

### 2.5 Mandatory Mod Manifest & Entry Points (`L-08`, `L-02`)

Every guest shared library MUST export three `extern "C"` symbols:

1. `bevy_abi_mod_manifest() -> *const BamManifest` (missing symbol -> `ModLoadError::MissingManifest`)
2. `bevy_abi_mod_init(api: *const BamHostApi, load_ctx: *mut BamLoadCtx, instance_out: *mut *mut BamInstance) -> FfiResult`
3. `bevy_abi_mod_shutdown(instance: *mut BamInstance)`

#### `BamManifest` Layout (`L-08`)

```rust
pub const BAM_MANIFEST_KNOWN_FLAGS: u32 = 0;

#[repr(C)]
#[derive(Debug, Copy, Clone)]
pub struct BamManifest {
    pub struct_size: u32,           // offset 0  (64b & 32b)
    pub abi_version: u32,           // offset 4  (64b & 32b)
    pub name: *const c_char,        // offset 8  (64b: 8B, 32b: 4B) — NUL-terminated UTF-8 canonical mod id (e.g. "combat_mod")
    pub version: *const c_char,     // offset 16 / 12               — NUL-terminated UTF-8 SemVer string (e.g. "0.4.1")
    pub flags: u32,                 // offset 24 / 16               — must match BAM_MANIFEST_KNOWN_FLAGS (0 in v0.2)
    pub reserved0: u32,             // offset 28 / 20               — must be 0
}
// 64-bit: MIN_V0_2_SIZE = 32, align = 8 (zero implicit padding)
// 32-bit: MIN_V0_2_SIZE = 24, align = 4 (zero implicit padding)
```

```c
typedef struct BamManifest {
    uint32_t struct_size;
    uint32_t abi_version;
    const char* name;
    const char* version;
    uint32_t flags;
    uint32_t reserved0;
} BamManifest;

typedef const BamManifest* (*BamManifestFn)(void);
typedef BamResult (*BamInitFn)(const BamHostApi* api, BamLoadCtx* load_ctx, BamInstance** instance_out);
typedef void (*BamShutdownFn)(BamInstance* instance);
```

- **Host Identity (`L-08`):** `ModHost` invokes `bevy_abi_mod_manifest()` **before** `bevy_abi_mod_init`, validates `struct_size`, `abi_version_is_compatible(ABI_VERSION, manifest.abi_version)`, non-empty UTF-8 `name` and `version`, `flags == 0`, and `reserved0 == 0`, populates `LoadedModInfo { id, name, version, path }`, and assigns a strictly monotonic `ModId(pub u64)` (`AtomicU64` starting at `1`; misleading "generational" doc removed).

### 2.6 Unified System, Query, Term, Component & Column Descriptors (`C-01`, `C-13`, `B-07`, `B-08`)

All six v0.1 system descriptors (`SystemDescriptor[V2/V3]`, `MultiQuerySystemDescriptor[V2/V3]`) and all seven `register_*system*` variants are replaced by **one** descriptor hierarchy (`BamTermDesc` -> `BamQueryDesc` -> `BamSystemDesc`) and **one** registration function (`register_system`).

#### Opaque Context Handles

```c
typedef struct BamHostCtx   BamHostCtx;   /* World-scoped registry/diagnostics handle */
typedef struct BamLoadCtx   BamLoadCtx;   /* Init-only transactional registration context */
typedef struct BamSystemCtx BamSystemCtx; /* Per-invocation system execution context */
typedef struct BamIter      BamIter;      /* Chunk + resource accessor for one declared query */
typedef struct BamCommands  BamCommands;  /* Deferred command buffer for the running system */
typedef struct BamInstance  BamInstance;  /* Guest-owned per-World mod instance state (ADR 0005) */
```

#### `BamTermDesc`

```rust
pub const BAM_TERM_KNOWN_FLAGS: u32 = 0;

#[repr(C)]
#[derive(Debug, Copy, Clone, PartialEq, Eq)]
pub struct BamTermDesc {
    pub component: BamComponent, // offset 0 (4B) — pre-resolved non-zero handle
    pub mode: AccessMode,        // offset 4 (4B) — READ..=RESOURCE_WRITE (0..=9)
    pub flags: u32,              // offset 8 (4B) — 0 in v0.2
}
// 64-bit & 32-bit: size = 12, align = 4 (zero implicit padding)
```

#### `BamQueryDesc`

```rust
pub const BAM_QUERY_KNOWN_FLAGS: u32 = 0;

#[repr(C)]
#[derive(Debug, Copy, Clone)]
pub struct BamQueryDesc {
    pub struct_size: u32,            // offset 0  (4B)
    pub flags: u32,                  // offset 4  (4B) — 0 in v0.2
    pub terms: *const BamTermDesc,   // offset 8  (64b: 8B, 32b: 4B) — NULL allowed iff term_count == 0
    pub term_count: usize,           // offset 16 / 12               — <= MAX_TERMS_PER_QUERY (32)
}
// 64-bit: MIN_V0_2_SIZE = 24, align = 8 (zero implicit padding)
// 32-bit: MIN_V0_2_SIZE = 16, align = 4 (zero implicit padding)
```

*Note:* Resource accesses (`AccessMode::RESOURCE_READ` / `RESOURCE_WRITE`) can be declared as terms inside a query (or inside a resource-only query where all terms are `RESOURCE_*`; a resource-only query registers `FilteredAccessSet` resource accesses without archetype iteration, while `res_ptr(iter, decl_index)` indexes directly into `terms[decl_index]`, see ADR 0003). A pure command/startup system sets `query_count = 0, queries = NULL`.

#### `BamSystemDesc` (`C-01`, `B-07`)

```rust
pub type BamSystemFn = unsafe extern "C" fn(sys_ctx: *mut BamSystemCtx, user_data: *mut c_void) -> FfiResult;
pub type BamRunIfFn  = unsafe extern "C" fn(user_data: *mut c_void) -> FfiBool;

/// Pins the system onto Bevy's main thread (`NonSendMarker` access in `GuestSystem::initialize`) (`B-07`).
pub const BAM_SYSTEM_FLAG_MAIN_THREAD: u32 = 1 << 0;
pub const BAM_SYSTEM_KNOWN_FLAGS: u32 = BAM_SYSTEM_FLAG_MAIN_THREAD;

#[repr(C)]
#[derive(Debug, Copy, Clone)]
pub struct BamSystemDesc {
    pub struct_size: u32,                  // offset 0  (64b) / 0  (32b)
    pub flags: u32,                        // offset 4        / 4        — BAM_SYSTEM_FLAG_*
    pub name: *const c_char,               // offset 8        / 8        — mandatory NUL-terminated UTF-8 system name
    pub queries: *const BamQueryDesc,      // offset 16       / 12       — NULL iff query_count == 0
    pub query_count: usize,                // offset 24       / 16       — <= MAX_QUERIES_PER_SYSTEM (8)
    pub callback: Option<BamSystemFn>,     // offset 32       / 20       — mandatory (`Some`)
    pub user_data: *mut c_void,            // offset 40       / 24       — opaque guest closure state
```

### 2.7 Complete Versioned `BamHostApi` & Context-Carrying Symbol Lookup (`C-03`, `C-04`)

Every core engine operation lives directly on `BamHostApi` as an `Option<unsafe extern "C" fn(...)>` slot. `ModRegistry::new()` registers **zero** built-in function symbols.

1. **`get_proc_address(const BamHostCtx* ctx, const char* name) -> const void*` (`C-04`):**
   - Takes an explicit `const BamHostCtx*` obtained from `load_host_ctx(load_ctx)` (during `init`) or `sys_host_ctx(sys_ctx)` (during system execution, or cached per-instance at `init`).

   - `CURRENT_REGISTRY`, `GLOBAL_SYMBOLS`, and `ACTIVE_INIT_CONTEXT` are **deleted** from `bevy_abi_mod_host_sys`.
2. **`last_error(const BamHostCtx* ctx, char* buf, size_t cap) -> size_t` (`C-07`):**
   - Copies the most recent human-readable diagnostic message recorded on `ctx` (per-`LoadContext` during `init`, or per-`GuestSystem` execution context during system run — zero global state!) as NUL-terminated UTF-8 into `buf[0..cap]` (when `buf != NULL && cap > 0`) and returns the full byte length excluding NUL (standard `snprintf` sizing convention).

### 2.9 `AbiPod` vs. `RawInsertable` vs. `ModComponent` Trait Boundary (`C-11`, `N-02`, `S-04`)

1. **`unsafe trait AbiPod: RawInsertable + Copy + Send + Sync + 'static`:**
   - Asserts cross-language C99/C++/Zig/Rust layout identity (`#[repr(C)]` or `#[repr(transparent)]`, non-packed), zero drop glue, and universal bit-validity across all fields (`#[derive(AbiPod)]` emits recursive compile-time `const _: () = assert_abi_pod::<FieldTy>();` checks for every field).
   - **Natural C alignment padding is permitted (`S-04`):** Standard `#[repr(C)]` structs with inter-field or trailing alignment padding (e.g., `{ x: f32, y: u64 }` or `{ a: u8, b: u32 }`) ARE valid `AbiPod` types (`size_of == sum_of_field_sizes` is NOT asserted). Uninitialized padding bytes inside `T` / `&[T]` are sound in Rust when every field is `AbiPod`, and raw command insertion (`S-04`, ADR 0003) copies raw bytes through `MaybeUninit<u8>` without ever forming `&[u8]` over struct padding.
   - **Permitted primitives (`C-11`):** `u8`, `i8`, `u16`, `i16`, `u32`, `i32`, `u64`, `i64`, `f32`, `f64`, `FfiBool`, `FfiEntity`, `ComponentUuid`, and `[T; N]` where `T: AbiPod`.
   - **Excluded primitives (`C-11`):** `u128` and `i128` (no C99 standard equivalent; 8-byte vs 16-byte alignment mismatch across LLVM/GCC/MSVC versions and x86_64/aarch64 targets) and `usize`/`isize` (pointer-width dependent; struct field offsets/strides are explicit in `BamHostApi`, while user component fields must use `u64`/`u32`). `bool` and `char` remain excluded (invalid bit-patterns).
2. **`unsafe trait RawInsertable: Send + Sync + 'static` (renamed from `FfiLayout`, `N-02`):**
   - Asserts only same-process raw byte move/drop compatibility (`IS_ABI_POD: bool` replaces `IS_POD`, alongside `IS_RAW_INSERTABLE: bool`).
   - `u128`, `i128`, `usize`, and `isize` implement `RawInsertable` (`IS_ABI_POD = false`) so host-defined structs containing `usize` or `u128` can support same-process raw insertion without falsely claiming cross-language `AbiPod`.
3. **`pub trait ModComponent: Sized + 'static` (renamed from `ExposableComponent`, `N-02`):**
   - Lives in **`bevy_abi_mod_sys`** (zero Bevy dependency; re-exported in `bevy_abi_mod_host` and `bevy_abi_mod`), completely decoupled from `bevy_ecs::component::Component`, `RawInsertable`, and `Default`.
   - Allows `#[repr(Rust)]` components containing `String`, `Vec<T>`, `bool`, `#[mod_field(skip)]`, or `#[mod_component(opaque)]` (as well as non-ECS nested sub-structs) to derive `ModComponent` with `IS_ABI_POD = false` and `IS_RAW_INSERTABLE = false`, while `bevy_abi_mod_host_sys` bounds `T: bevy_ecs::component::Component + ModComponent` (and requires `RawInsertable` / `Default` only on opt-in `ComponentOptions` raw-insert / `with_default()` builders per `B-01`).

| `FfiLayout` + `IS_POD` | `RawInsertable` + `IS_ABI_POD` | *(Rust trait only)* | `bevy_abi_mod_sys` |
| `#[derive(ModExposable)]` + `ExposableComponent` | `#[derive(ModComponent)]` + `ModComponent` | *(Rust macro/trait)* | `bevy_abi_mod_macros` / `bevy_abi_mod_sys` (re-exported in `bevy_abi_mod_host`) |
| `GuestComponent` | `GuestComponent` | *(Rust trait)* | `bevy_abi_mod_guest` |

## 3. Alternatives Considered

| Alternative | Why Rejected |
|---|---|
| **Keep Separate Single-Query and Multi-Query Descriptors** | Doubles host parser code, FFI surface, and test matrix for zero runtime gain (`query_count == 1` is a stack-allocated 24-byte `BamQueryDesc` during `init` only). |
| **Return `BamColumnInfo` by Value (`extern "C" fn(...) -> BamColumnInfo`)** | 48-byte struct return conventions differ subtly across x86_64 Windows, SysV, ARM64, and 32-bit targets and forfeit an explicit `FfiResult` status code. |
| **Represent `ComponentUuid` as `{ lo: u64, hi: u64 }` or `u128`** | `u128` has unstable cross-compiler alignment (`C-11`), and `u64` has 4-byte alignment on 32-bit x86 SysV vs 8-byte on 32-bit MSVC/ARM. `[u8; 16]` is 16 bytes, align 1 everywhere. |
| **Keep `get_proc_address` for Built-In Commands/Resources** | Requires string comparison, fallback alias chains, and context-carrying plumbing on every mod init when a flat `BamHostApi` table resolves all 27 built-ins in `O(1)` at zero cost. |

## 4. Consequences & Verification Criteria

1. **Compile-time C & Rust layout parity (`C-12`):** `cargo xtask header` emits `include/bevy_abi_mod.h` with `_Static_assert` checks for every offset and size in §2.10, compiled under `-std=c99 -Wall -Wextra -Wpedantic -Werror` in CI (`T-09`).
2. **Forward compatibility test (`C-02`):** Appending a synthetic `v0.3` `Option<extern "C" fn()>` slot to a test copy of `BamHostApi` / `BamSystemDesc` preserves `MIN_V0_2_SIZE` (`224` / `104` on 64-bit) and accepts older `v0.2` callers cleanly.
3. **Zero ambient globals (`C-04`):** `ModRegistry::new()` starts with zero built-in function symbols, and `grep -rn "thread_local!" crates/bevy_abi_mod_host_sys/src` returns empty, unblocking parallel `cargo test` (`T-03`).
4. **Type safety & collision rejection (`C-10`, `C-11`, `C-13`, `M-04`, `M-05`):** Two mods defining `Health` coexist under `"mod_a::Health"` and `"mod_b::Health"`; layout mismatches fail with `TYPE_MISMATCH`; `#[derive(AbiPod)]` on a struct containing `u128` or `usize` fails `trybuild`; and invalid UTF-8 setters return `INVALID_UTF8` without mutating host state.
